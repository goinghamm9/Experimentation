How real orders get placed

This dashboard is read-only for your brokerage. Execution happens in Claude Code through Robinhood's official MCP server, with you confirming each order.

  1. Fund the Agentic account. In the Robinhood app, open and fund the account Robinhood designates for agent trading. Only put in money you are prepared to have traded by this strategy.
  2. Connect Claude Code to Robinhood. In a terminal, in this folder, run:
    claude mcp add robinhood-trading --transport http https://agent.robinhood.com/mcp/trading
    Claude Code will ask you to log in to Robinhood the first time it uses it.
  3. Make a plan. Run python -m engine plan (or the Today's plan tab), or ask Claude Code to run the robinhood-rebalance skill, which reads your real positions and builds the same plan.
  4. Confirm each order. Claude shows every order with its reason and waits for your yes before sending it. If the plan is BLOCKED (for example, stale prices), nothing should be sent.

Robinhood MCP tools

Tool names are discovered from the Robinhood server at run time and saved here, not hard-coded in the engine. If Robinhood renames a tool, re-run discovery.
