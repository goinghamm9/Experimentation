# Sources and assumptions (merged by the orchestrator)

ID convention: agent letter plus number (A1, B1, C1, D1, E1). Sources list publisher, URL, date accessed, what is measured, geography, year, and verification depth (page read, search snippet, or search summary). Assumptions list the statement, the reasoning, and what would change it. Orchestrator decisions live in decisions.md (O1, O2, ...).
